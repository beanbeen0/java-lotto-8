# 로또

## 프로젝트 개요

---

투입한 금액에 맞추어, 로또를 발권해주는 로또 발권기입니다. 
발권 후에는 당첨 번호를 입력해, 당첨 통계를 볼 수 있습니다. 

`시스템의 순서`는 
"구입 금액 입력 -> 로또 구매 내역 출력 -> 당첨 번호 입력 -> 보너스 번호 입력 -> 당첨 통계 출력" 입니다.


## 구현 기능 목록

---

### `로또 발행`
- 1개의 로또를 발권한다.
  - 로또의 숫자 범위는 1~45까지이다.
  - 중복 되지 않는 숫자 6개를 뽑아 1개의 로또를 발권한다.

### `로또 구매`
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다. 이 때, 로또 1장의 가격은 1000원이다.
- 투입 금액이 1000원 단위인지 검증한다.

### `로또 당첨 판정`
- 로또 번호와 당첨 번호, 보너스 번호를 비교해 당첨 등수를 판정한다. (보너스 번호 일치는 당첨 번호 갯수에 포함되지 않는다.)
- 비교 기준은 중복 되지 않는 당첨 번호 6개와 보너스 번호 1개이다.
- 당첨은 1부터 5등까지 있으며, 당첨 기준은 다음과 같다.
  - 당첨 기준 
  
    | 등수   | 조건                | 당첨 금액          |
    |------|-------------------|----------------|
    | 1등   | 6개 번호 일치          | 2,000,000,000원 |
    | 2등   | 5개 번호 + 보너스 번호 일치 | 30,000,000원    |
    | 3등   | 5개 번호 일치          | 1,500,000원     |
    | 4등   | 4개 번호 일치          | 50,000원        |
    | 5등   | 3개 번호 일치          | 5,000원         |

### `당첨 기록`
- 각 당첨 기준과 당첨된 로또 갯수로 구성된 당첨 내역을 만든다.

### `당첨 통계`
- 총 수익률을 산출한다. 수익률은 (총 상금) / (투입 금액)의 백분율이다.

### `예외 출력`
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

### `입력`
- `구입 금액`을 입력받는다.
  ```text
  구입금액을 입력해 주세요.
  8000
  ```
  - 입력 프롬프트 '구입금액을 입력해 주세요.' 를 출력한다.
  - 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

- `당첨 번호`를 입력받는다.
    ```text
    당첨 번호를 입력해 주세요.
    1,2,3,4,5,6
    ```
    - 입력 프롬프트 '당첨 번호를 입력해 주세요.' 를 출력한다.
    - 번호는 쉼표(,)를 기준으로 구분한다.
    - 당첨 번호의 범위는 1~45이다.
    - 당첨 번호는 서로 중복 되지 않는다.
- `보너스 번호`를 입력받는다.
    ```text
    보너스 번호를 입력해 주세요.
    7
    ```
    - 입력 프롬프트 '보너스 번호를 입력해 주세요.' 를 출력한다.
    - 보너스 번호의 범위는 1~45이다.
    - 보너스 번호는 이전에 입력 받은 6개의 당첨 번호들과 중복되지 않는다.


### `출력`
- `발권 정보`를 출력한다
  - 발행한 로또 수량 및 번호를 출력한다. 
  - 로또 번호는 오름차순으로 정렬하여 보여준다.
  ```text
  8개를 구매했습니다.
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  [7, 11, 16, 35, 36, 44]
  [1, 8, 11, 31, 41, 42]
  [13, 14, 16, 38, 42, 45]
  [7, 11, 30, 40, 42, 43]
  [2, 13, 22, 32, 38, 45]
  [1, 3, 5, 14, 22, 45]
  ```
- `당첨 내역`을 출력한다.
  ```text
  3개 일치 (5,000원) - 1개
  4개 일치 (50,000원) - 0개
  5개 일치 (1,500,000원) - 0개
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
  6개 일치 (2,000,000,000원) - 0개
  ```
